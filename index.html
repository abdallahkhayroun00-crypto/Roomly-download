Getting started

From this page to your home.

Three simple steps once an Android test build is published.

01

Download the APK

When a test release is available, the button above links to its Android installation file.

02

Install on Android

Open the downloaded file. Your phone may ask you to allow installation from your browser.

03

Get organized together

Open Roomly and start organizing your shared place with your roommates.

Installing on Windows

When the desktop build is published, download the installer and run it. If it's a ZIP, extract the entire folder first, then run Roomly.exe from inside it. Keep the other files alongside the app.
